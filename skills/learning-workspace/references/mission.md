# Mission record

Use this reference only when creating or revising `MISSION.md` inside the
approved teaching workspace.

Keep the record short:

```markdown
# Mission: Topic

## Why

State the concrete real-world outcome the learner wants.

## Success looks like

- One observable capability.
- Another observable capability when needed.

## Constraints

- Time, budget, accessibility, prior commitments, or learning preferences.

## Out of scope

- Adjacent topics intentionally deferred.
```

Use one mission per workspace. Push a vague goal toward a result the user can
observe. Confirm revisions before writing. When a mission changes after
learning has begun, update the mission and add a learning record only after the
user accepts the new direction.
