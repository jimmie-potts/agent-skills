# Learning glossary

Use this reference only when adding or revising an understood term in
`GLOSSARY.md` inside the approved teaching workspace.

Use a compact entry:

```markdown
**Canonical term**

One or two sentences that distinguish the concept.

Avoid: ambiguous alias, misleading alias
```

Add a term only after the learner can use it correctly. Choose one canonical
word when several compete, list aliases worth avoiding, and flag field-wide
ambiguity. Use accepted glossary terms in later definitions, lessons, and
records.

Revise a definition when demonstrated understanding deepens. Keep the glossary
a compressed language record, not a dictionary copied from sources or a list
of every term encountered.
