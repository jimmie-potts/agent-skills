# Learning record

Use this reference only after the learner demonstrates durable understanding,
states relevant prior knowledge, corrects a misconception, or accepts a mission
change.

Store records under `learning-records/` in the approved teaching workspace.
Follow an existing numbering convention. When none exists, use sequential names
such as `0001-short-topic.md`.

Use the smallest useful format:

```markdown
# What was learned or established

State what the learner can now use, the evidence that demonstrated it, and why
it changes a future lesson.
```

Optional sections may record status, evidence, or implications when they add
information. Do not record material merely covered, repeat a glossary
definition, or create a session-by-session journal.

When later evidence corrects a record, preserve the history using the
workspace's supersession convention instead of silently rewriting what the
learner previously demonstrated.
