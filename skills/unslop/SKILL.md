# Unslop

Use this skill for a requested editorial pass or a draft with a specific, material
clarity problem. Do not invoke it solely because the response is for a person.

Identify the sentences that make the reader work harder. Cut filler, replace vague
claims with supported specifics, and split dense sentences. Keep the intended
tone and use formatting when it helps. Make only the edits the draft needs.

Preserve technical meaning, facts, citations, quotations, code, commands,
identifiers, required terminology, schemas, contracts, acceptance criteria,
evidence, status claims, and required structure. Do not invent opinions, actors,
measurements, events, or sources. Follow user and repository instructions when
style advice conflicts with them.

For a comprehensive edit with persistent patterns, read the
[optional pattern catalog](references/patterns.md). Its 31 rules are examples,
not a checklist or punctuation bans. Compare the result with the original to
confirm that meaning and evidence survived the edit.

This skill is editorial only. It grants no filesystem, Git, Jira, GitHub,
network, publication, or other external mutation authority.
