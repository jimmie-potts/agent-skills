# Choose an implementation approach

Read when decomposing or delegating work. Follow [execution choices](model-selection.md)
and [task planning](task-planning.md). Planning consumers only propose work.

Implement directly or delegate according to the work. A bounded worker can
isolate a research question or implementation task. Parallel workers help when
inputs, contracts and mutable resources are independent. An advisory pairing
can help when a worker benefits from consultation at decision points. None is
required by a complexity rating or model name.

Define each assignment's outcome, source revision, acceptance evidence,
constraints and ownership in a [bounded brief](worker-briefs.md). Workers return
proposals and evidence; the delivery coordinator owns durable effects. Keep
independent review separate from implementation and advice.

Use the active host's supported settings and controls. Retain explicit user
limits; unavailable optional controls do not block direct work. When a return
fails acceptance, diagnose the failure before retrying or changing settings.
Missing facts, permissions or product decisions need their own resolution.
Read [worker continuation](worker-continuation.md) for corrections, replacement
or handoff. Reassess on repeated failure or changed scope rather than following
a fixed model or effort ladder.
